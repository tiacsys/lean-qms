Glossary

General Terms

CAPA

Corrective and Preventive Action, formal process required by FDA Quality System Regulation (21 CFR 820), and ISO 62304, MDR 2017/745

CVE

Common Vulnerability Exposure, publicly know vulnerability of a software element.

DSwDS

Detailed Software Design Specification, a document that contains the detailed software design for a software system.

DSwRS

Detailed Software Requirements Specification, a document that contains the detailed software requirements for a software system.

FMEA

Failure Mode and Effects Analysis, a systematic approach to identify potential failure modes, their causes and effects, and to prioritize them based on their severity, occurrence, and detectability.

FTA

Fault Tree Analysis, a top-down approach to identify the root causes of a failure.

HMI

Human-Machine Interface

Risk Control Measure

A measure implemented to reduce the risk of a hazardous situation to an acceptable level.

Software Hazard

A software state that, in combination with a particular set of conditions, can lead to a hazardous situation.

Software Risk Class

A classification of software based on the severity of the harm that can be caused by a software failure, and the probability of occurrence of such a failure.

SouP

Software of Unknown Provenance — pre-existing software that is integrated into a medical device software product without the manufacturer having performed the full software development lifecycle activities for that component. Includes open-source libraries, third-party packages, SDKs, operating system components, and vendor-supplied firmware HALs.

SwDS

Software Design Specification, a document that contains the software design for a software system.

SwRAR

Software Risk Assessment Report is a document that contains the results of the software risk assessment, including the identified software hazards.

SwRS

Software Requirements Specification, a document that contains the software requirements for a software system.

QMS Document Types

No QMS document types defined.
